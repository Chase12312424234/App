DROPFINDER Preview

Every track. Every drop.

Paste a YouTube DJ set. Get the tracklist with timestamps, links, and a button that jumps straight to each drop.

This preview can't process new sets. That needs the DropFinder server, which runs on your computer: .venv/bin/dropfinder serve, then open http://127.0.0.1:8000. See the README for setup.

    Listen

    Downloads the set's audio and takes a 12-second sample every 45 seconds.

    Identify

    Each sample is matched with Shazam, then merged into one row per track.

    Find the drop

    Looks for the biggest jump in bass and loudness after a build-up.

    Example result from a real DropFinder run. In this preview, timestamps and Play drop open YouTube in a new tab; the full app plays them in an embedded player.
